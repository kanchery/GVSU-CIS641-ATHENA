# Autonomous AI Agent Workflow Orchestration Platform

**Team:** Athena  
**Team Member:** Yogesh Aravind Karthikeya Kancherla

## Project Overview

This project is a platform that allows multiple AI agents to work together on a larger task. The user gives the system an overall goal, and the system divides it into smaller tasks. These tasks are assigned to suitable AI agents and can be completed one after another or at the same time.

The platform also monitors task progress, handles failed tasks, controls what tools and data each agent can access, and asks for human approval before important actions are completed. The main purpose of this project is to make AI-based work easier to organize, monitor, and control.

## Main Features

- Create and manage AI agents
- Enter an overall goal
- Divide the goal into smaller tasks
- Assign tasks to suitable AI agents
- Run tasks in sequence or in parallel
- Monitor workflow progress
- Retry failed tasks
- Control access to tools and data
- Request human approval for important actions
